# WinUI 3 + .NET para aplicación principal

**Status:** Accepted

## Decisión
Usar C# + .NET + WinUI 3 para la aplicación Windows.

## Motivo
Integración nativa con Windows, procesos, filesystem, lifecycle, instalación y
ecosistema `Microsoft.Extensions`. La aplicación es Windows-first.

## Consecuencia
Python queda fuera de la UI y se consume como worker local.

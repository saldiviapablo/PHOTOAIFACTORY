# Definition of Done

Una historia no está terminada hasta que:

- requisito/ADR asociado identificado;
- unit tests pasan;
- integration tests aplicables pasan;
- error paths probados;
- logs estructurados presentes;
- cancelación considerada;
- retry/idempotencia considerados;
- no modifica originales;
- no crea overwrite silencioso;
- schema/contract versionado si aplica;
- benchmark registrado si toca IA/performance;
- licencia revisada si agrega dependencia/modelo;
- documentación actualizada;
- recovery después de crash evaluado para etapas durables.

# Third-party Review Checklist

Antes de agregar un componente/modelo al instalador:

- [ ] Nombre exacto.
- [ ] Versión/tag/commit.
- [ ] URL oficial.
- [ ] Archivo de licencia descargado.
- [ ] Licencia de **código**.
- [ ] Licencia de **pesos/checkpoint**.
- [ ] Licencia/procedencia de dataset relevante documentada.
- [ ] SHA-256.
- [ ] NOTICE/attribution requerida.
- [ ] ¿Permite redistribución comercial?
- [ ] ¿Impone source disclosure/offer?
- [ ] ¿Tiene cláusula non-commercial?
- [ ] ¿Tiene restricciones de trademark?
- [ ] Dependencias transitivas revisadas.
- [ ] Entrada agregada a `components.lock.json`.
- [ ] Legal review si GPL/copyleft o términos ambiguos.
